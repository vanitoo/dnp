# DNP 3.15.2-1: восстановление папок и PDF после ошибки

Основа: `Code_v3.15.2_coefficient_pdf.gs`. Отдельная версия, без owner-backend.
Рабочая `main` не изменена. Развертывание Web App не требуется.

## Что исправлено

- Если запомненная папка удалена/перемещена, поиск идёт сначала по текущему родителю.
  Если активной папки нет, создаётся новая и сохраняется её ID.
- Ошибки доступа (403), Drive API и наличие нескольких одноимённых папок
  **не** приводят к автоматическому созданию новой.
- При ошибке пакетной обработки запись `DNP_ACTIVE_PDF_JOB_V1`
  освобождается только для текущего `runId`.
- Старые записи запусков без обновления более 10 минут считаются устаревшими.
  Активные чужие запуски блокируются, чтобы не получить гонку при записи PDF.
- Новый PDF сначала создаётся, старый переносится в корзину **после**
  успешного создания нового. Если старую версию нельзя удалить из-за прав,
  получаем явную ошибку; новый PDF не теряется.

## Установка

Использовать **в паре**:
- `Code_v3.15.2-1_folder_lock_fix.gs` → вставить в единственный `Code.gs` проекта
- `appsscript_v3.15.2-1.json` → вставить в `appsscript.json`

Каждый пользователь должен иметь `Редактор` к Google-таблице,
корневой папке квитанций (`outputFolderId`) и доступ к шаблону
(`templateDocId`). Для `drive` потребуется Google OAuth-подтверждение.

Тестировать сначала **на копии таблицы и папки**.
Проверить: (1) существующий месяц, (2) удалённый месяц,
(3) ноябрь после ошибки октября, (4) повтор PDF за месяц,
(5) другой редактор и общий каталог.

## Известные ограничения

- Это не проверка на живом Google Drive: проведены синтаксическая проверка
  и тесты на имитированных ответах API.
- Статус «404 / File not found» не всегда позволяет отличить
  действительно удалённый файл от файла, скрытого правами; поэтому
  требуется полный `drive` и права на общую папку.
- Для обычного My Drive разные пользователи могут владеть созданными файлами.
  Если одному из них запрещено удалять старый PDF другого владельца,
  новый останется, а операция выдаст ошибку: старый файл потребуется
  убрать владельцу вручную.
